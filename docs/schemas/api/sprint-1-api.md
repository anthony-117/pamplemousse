# Sprint 1 API Contract (draft v0.1 — 2026-10-26)

Goal: "Pick Rome and see everything about it." Code-first: the real OpenAPI file is generated by `pamplemousse` and used to generate the Dart client in `chocomousse`. This page is the agreed shape before coding.

Base URL: `/api/v1` · JSON · errors use RFC 9457 Problem Details.

## Endpoints
| Method | Path | Purpose | Sources | Cache |
|---|---|---|---|---|
| GET | `/destinations?q=rom&limit=10` | City search / autocomplete | `destinations` table (GeoNames seed) | DB |
| GET | `/destinations/{id}` | One city + its country | DB | DB |
| GET | `/destinations/{id}/overview?passport=LB&currency=USD&from=2027-04-10&to=2027-04-15` | Country facts, weather, exchange rate, holidays in range, visa, advisory | DB + Open-Meteo, Frankfurter, Nager.Date | Redis: weather 3 h, rates 12 h, holidays 30 d |
| GET | `/destinations/{id}/places?category=attraction&limit=20` | Top attractions | OpenTripMap (+ Google Places details) | Redis 24 h |
| GET | `/destinations/{id}/places?category=restaurant&limit=20` | Top restaurants | Google Places | Redis 24 h |
| GET | `/places/{id}` | Place details (photos, hours, rating) | Google Places | Redis 24 h |
| GET | `/destinations/{id}/events?from=…&to=…` | Events during the dates | Ticketmaster | Redis 6 h |
| GET | `/health` | Liveness for Cloud Run | — | — |

## Rules
- Weather: Open-Meteo forecasts cover ~16 days. For later dates return `"kind": "climate"` (historical averages) instead of a forecast.
- Each section is independent: if one provider fails, return the others and set that section to `null` with a `warnings` entry, rather than failing the whole request.
- `passport` and `currency` default from the signed-in user's profile; anonymous use is allowed in Sprint 1.
